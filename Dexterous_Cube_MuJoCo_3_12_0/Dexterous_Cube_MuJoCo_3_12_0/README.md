# 灵巧手玩魔方 · MuJoCo 3.12.0

这是一套**双灵巧手魔方教学仿真**：双手建立接触抓持，手腕退让，魔方内部伺服完成转层，再由手指重新抓持。提供网页六面按键、键盘快捷键、动作序列、六步打乱、撤销、历史逆序还原、释放下落和复位。

网页画面由本机 MuJoCo 实时渲染。模型是本工程原创的简化灵巧手，**每只手有 20 个手指自由度**，两只手另有 2 个手腕退让滑台；43 个执行器包括 40 个手指、2 个滑台和1 个内部转层伺服。

## Windows 一键运行

1. 安装 **64 位 Python 3.11**，勾选 **Add Python to PATH**；已有 Python 3.11.6 可以使用。
2. **完整解压 ZIP**，打开 `Dexterous_Cube_MuJoCo_3_12_0` 文件夹。
3. 双击 **`run_windows.bat`**。首次会建立 `.venv` 并联网安装依赖，随后自动打开浏览器。
4. 点击「观看完整演示」，或等待双手抓持成立后点击六面按键。

默认网页地址为 `http://127.0.0.1:8899`。需要在运行仿真的同一台电脑上打开，启动命令窗口保持运行。结束时在命令窗口按 **Ctrl+C**。

`requirements.txt` 已固定 `mujoco==3.12.0`，并包含 **Pillow**（提供 `PIL`）、NumPy 和录像依赖。无需单独安装名为 PIL 的包。

想直接看独立窗口演示，可双击 **`run_demo_windows.bat`**。约 13.6 秒完成三步打乱与逆序还原，窗口会保留到手动关闭。原生窗口用于观看演示，交互控制使用网页。

## 操作与魔方记号

| 面 | 按键 | 初始颜色 |
| --- | --- | --- |
| 上面 | U | 白 |
| 右面 | R | 红 |
| 前面 | F | 绿 |
| 下面 | D | 黄 |
| 左面 | L | 橙 |
| 后面 | B | 蓝 |

一个字母表示**从该面外侧正视时顺时针转 90°**。加英文单引号表示逆时针，例如 `R'`；加 `2` 表示半圈，例如 `U2`。

- 网页可选择顺时针、逆时针和 180°，再点击面按键。
- 键盘按 U/R/F/D/L/B 转面；按住 **Shift** 可临时使用逆向。
- **空格**暂停/继续，**S** 六步打乱，**H** 历史逆序还原，**Z** 撤销一步，**Esc** 清空待执行队列。
- **R 是右面转动**。复位使用网页「复位场景与抓持」按钮。
- 动作序列可输入 `R U R' U'`，点击执行；一次最多 40 步。

「清空队列」会保留正在进行的转层，让它到达端点后停止。暂停会冻结物理计算。释放魔方要求当前动作和队列已完成，释放后按复位重新开始；本工程没有从托盘自主拾取魔方的手臂。

展开图展示**已完成转层**的贴纸状态，实时三维画面展示正在进行的转动。转层端点完成后，展开图和历史同时更新。

## 还原方式与辅助控制

**逆序还原使用本次操作的已知历史**。例如演示先执行 `R U F'`，再执行 `F U' R'`，回到初始六面同色状态。撤销通过执行最后一步的逆操作实现，因此会产生一条新的历史记录。历史逆序执行不是最短步数求解。

本工程没有任意状态的通用魔方解算器、视觉识别、强化学习操作策略或真机接口。控制实现如下：

1. 手指由位置伺服驱动，带力矩上限；物体、手指和托盘接触由 MuJoCo 计算。
2. 至少三个指尖接触、且接触来自双手并持续一定物理步数，才激活**辅助抓持 weld**。
3. 手腕退让、手指张开期间，辅助约束保持魔方核心位姿。
4. **转层力矩由魔方内部位置伺服提供**，手指配合退让和重新抓持。

魔方包含 26 个有空间位置与朝向的小块和 54 枚固定在小块上的贴纸。每次选择一层的 9 个小块，围绕内部 hinge 转动；达到端点并稳定后，更新小块的整数位置/朝向并重建连接拓扑，保留核心位姿、速度及手关节状态。

魔方约 66 mm 宽，质量约 0.172 kg。小块之间的内部卡扣、弹簧、摩擦和自碰撞未建模，灵巧手也不进行自碰撞检测。端点重建不是完整的连续机械魔方内部结构模型。

模型无外部网格依赖；几何体、手指和魔方均由本项目的 MJCF 生成代码构建。新增代码与模型使用 MIT 许可。

## 命令行运行

在实际解压目录打开命令提示符或 PowerShell。下面的命令输入终端，**不要输入 Python 的 `>>>` 解释器**。

```bash
python -m pip install -r requirements.txt
python start_web.py

# 端口占用，或需要降低画面分辨率时。
python start_web.py --port 8900 --width 640 --height 360 --fps 15

# 无窗口完成演示与验证。
python dexterous_cube.py --headless --verify

# 录制实际 MuJoCo 画面，录像要求使用 --headless。
python dexterous_cube.py --headless --verify --video results/my_demo.mp4
```

Windows 路径有空格时，给路径加双引号。示例 CMD：

```bat
cd /d "D:\你的解压位置\Dexterous_Cube_MuJoCo_3_12_0"
python start_web.py
```

PowerShell 使用 `cd "D:\你的解压位置\Dexterous_Cube_MuJoCo_3_12_0"`。在 `>>>` 中先输入 `exit()` 返回终端。

网页默认设定 20 FPS，实际刷新率取决于显卡并在页面显示。物理计算和渲染使用独立线程及状态快照，避免慢渲染阻塞物理步骤。Linux 无桌面环境时入口默认尝试 EGL；Windows 使用 MuJoCo 默认 OpenGL 后端。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `run_windows.bat` | Windows 安装依赖并启动网页 |
| `run_demo_windows.bat` | Windows 原生演示窗口 |
| `start_web.py` | 本机网页服务入口 |
| `dexterous_cube.py` | 演示、数值验证、窗口与录像 |
| `dexcube/cube.py` | 小块位置/朝向、贴纸、合法转层及历史逆序 |
| `dexcube/scene.py` | 双灵巧手、滑台、魔方和辅助抓持的 MJCF 生成 |
| `dexcube/simulation.py` | 接触检测、伺服、动作阶段与拓扑重建 |
| `dexcube/webserver.py` | 控制队列、物理线程、JPEG/MJPEG 实时画面 |
| `web/` | 中文控制界面、键盘、动作序列和展开图 |
| `scene.xml` | 可独立加载的初始 MJCF，含 `grasp_ready` 关键帧 |
| `tools/` | 魔方逻辑、物理、网页接口与按键检查，以及场景导出 |
| `results/` | 已录制视频与验证报告 |

单独加载 `scene.xml` 不会执行 Python 中的抓持检测和转层控制；使用工程入口运行完整动作。可用 `python tools/export_scene.py` 重新生成场景。

## 已执行验证

验证环境为 **MuJoCo 3.12.0 / Python 3.12 / Linux EGL**：

- 完整演示完成 6 次转层，末态还原，最大手指关节越限 **0 rad**。
- 稳定抓持时检测到 8 个指尖接触，峰值达到 10 个；辅助抓持的位置误差约 **0.066 mm**。
- 转层端点角误差约 **0.096°**，端点拓扑重建的小块位置变化约 **0.052 mm**。
- 逻辑检查覆盖六面共 18 种动作、逆操作、四次转动恒等式、非交换性、组合动作恒等式及 30 步历史逆序。
- 物理动作合并覆盖 U/R/F/D/L/B、正逆向及半圈；打乱后历史还原成立。
- 关闭手部接触的反例中，辅助抓持未激活、排队的转层未执行，魔方落到托盘。
- 释放测试中，核心高度由约 **0.205 m** 降到 **0.069 m**。
- 9 组实际本机网页检查通过：资源与 JPEG/MJPEG、转层后的渲染模型切换、撤销、转层中暂停/继续、历史还原、序列排队/清空、无效和过期请求处理、相机切换、释放与复位重抓持。
- JavaScript 动作格式、六面按键、逆向、半圈、空白分隔与错误输入检查通过；导出的 MJCF 可加载。

当前环境没有执行 Windows 原生窗口和浏览器界面视觉操作。已验证物理、实际渲染图像、网页服务和命令接口；本机窗口与页面显示仍依赖显卡、驱动和浏览器。

复查命令：

```bash
python tools/verify_cube.py
python tools/verify_web.py
node tools/verify-controls.mjs
```

网页服务退出时会更新 `results/web_last_run.json`。验证报告见 `results/validation_*.json`。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到 requirements.txt 或 Python 文件 | 完整解压，进入本工程目录；推荐双击 `run_windows.bat` |
| `No module named PIL` | 用运行入口的同一个 Python 安装 `requirements.txt`；其中已包含 Pillow |
| 网页打不开 | 保持命令窗口运行，在同一台电脑打开打印的本机地址 |
| 8899 端口被占用 | `run_windows.bat --port 8900` |
| OpenGL/GLFW 初始化失败 | 更新显卡驱动；先用 `--headless --verify` 检查物理部分 |
| 释放后无法重新抓持 | 点击「复位场景与抓持」重新初始化 |
| 还原按钮提示等待 | 等当前动作队列完成后，再执行逆序还原 |
| 英文记号被拒绝 | 使用 U/R/F/D/L/B、英文单引号或 2，例如 `R U R' U2` |

官方引擎资料：[MuJoCo 3.12.0](https://pypi.org/project/mujoco/3.12.0/)、[MuJoCo 文档](https://mujoco.readthedocs.io/en/3.12.0/)。
