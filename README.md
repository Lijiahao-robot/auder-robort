## 可交互式 MuJoCo 仿真（支持键盘实时控制）
无需实体硬件，在电脑里用键盘直接操控机器人：启停行走、调整步幅、步态速度、原地转向，实时观察平衡状态。
 仿真模型 ，模型自由度、关节限位、质量参数与实物 1:1 对齐。

### 仿真功能清单

- 键盘 `Space`：启动 / 停止 ZMP 行走步态
- 键盘 `W / S`：增大 / 减小行走步幅
- 键盘 `A / D`：原地左转、原地右转
- 键盘 `↑ / ↓`：加快 / 降低步态周期（行走快慢）
- 键盘 `R`：机器人复位到初始站立姿态
- 实时可视化：重心 CoM、ZMP 零力矩点、IMU 姿态角曲线
- ### 仿真调试提示

1. 打开 viewer 侧边面板，可以查看各关节角度、力矩、IMU 传感器数据。
2. 观察 ZMP 点是否落在支撑多边形内部，一旦跑出支撑区域机器人会倾倒，用来调平衡控制器。
3. 仿真调好步态参数后，可以直接导出步态序列，下发给实物机器人（mujoco)
