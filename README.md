 1.硬件概况

- 自由度：12DOF 舵机双足人形（下肢每腿 6 舵机，无手臂，专注步态行走）
- 结构：全部零件 3D 打印，低成本创客方案；
- 驱动：普通数字舵机，STM32 底层板卡做舵机控制；IMU（MPU6050）采集机身姿态角，用于平衡反馈。
- BOM 清单：仓库`hardware/bom.md`，包含舵机型号、轴承、螺丝、主控、电源选型。
- 机械模型：`mechanical/`目录，STEP 装配模型，可直接切片打印，也能导入 MuJoCo 生成 MJCF。
 2. 软件栈（ROS2 Humble）

1. **底层固件 firmware/**：STM32 工程，舵机角度控制，IMU 姿态解算，串口向上位机发送状态。
2. **ROS2 上位机包 robot_ws/**
   - 步态生成：基于 ZMP 零力矩点的预生成行走轨迹；
   - 平衡控制器：IMU 反馈校正姿态，倾角修正；
   - 通信节点：串口 ↔ ROS2 话题，下发舵机目标角度，上传姿态数据；
3. **仿真 simulation/**
   - MuJoCo XML 模型（MJCF），和实物 1:1 简化；
   - Python 仿真脚本，可离线调试步态，**不用硬件就能先调走路算法**，再下真机。
3. 项目两大用途

 仿真：MuJoCo 里面调步态、测试摔倒恢复、参数整定，不用消耗舵机。
 实物：3D 打印 + 舵机组装，ROS2 上位机控制真实双足行走。
4. 编译环境要求

- Ubuntu 22.04 + ROS2 Humble/ Windows 11 + mujoco-c++
- Python 3.10，mujoco>=2.3.7
- 固件：STM32CubeIDE 编译烧录
